## 機能一覧

### 認証

- **新規会員登録** — メールアドレス・パスワードでアカウント作成
- **ログイン / ログアウト** — トークンベースの認証
- **プロフィール編集** — 名前・メールアドレスの変更
- **プロフィール画像** — JPG / PNG / GIF / WebP（最大2MB）のアップロード
- **パスワード変更** — 現在のパスワードによる確認あり
- **退会** — パスワード確認後にアカウントとデータを完全削除

### スケジュール管理

- **カレンダービュー** — 月・週・日の表示切り替え
- **リストビュー** — 開始日時の昇順で一覧表示
- **スケジュール作成** — フォームからタイトル・説明・日時・カラーを登録
- **日付クリック作成** — カレンダーの日付をクリックでその日のモーダルを開く
- **スケジュール編集** — カレンダーイベントまたはリストから編集
- **スケジュール削除** — リスト・カレンダー・編集モーダルから削除
- **ドラッグ＆ドロップ** — カレンダー上でイベントを移動（時刻変更）
- **リサイズ** — イベント下端をドラッグして終了時刻を変更
- **カラーテーマ** — スケジュールごとに6色から色を選択

| 色名         | カラー  |
| ------------ | ------- |
| インディゴ   | #6366f1 |
| バイオレット | #8b5cf6 |
| スカイ       | #0ea5e9 |
| エメラルド   | #10b981 |
| アンバー     | #f59e0b |
| ローズ       | #f43f5e |

### UI / UX

- **トースト通知** — 作成・更新・削除の完了時に右上に表示
- **レスポンシブデザイン** — PC・タブレット・スマートフォン対応
- **モーダルアニメーション** — スムーズな表示・非表示
- **マテリアルアイコン** — Google Material Symbols Rounded 使用

## 操作方法

### 1. アカウント登録

1. トップページ（ `/login` ）から「新規登録」リンクをクリック
2. 名前・メールアドレス・パスワード（8文字以上）を入力
3. 「アカウントを作成」をクリック → メインページへ遷移

### 2. スケジュールの作成

**方法A：新規作成ボタン**

1. ヘッダー右上の「＋ 新規作成」ボタンをクリック
2. タイトル・説明（任意）・開始日時・終了日時・カラーを入力
3. 「保存する」をクリック

**方法B：カレンダーの日付をクリック**

1. カレンダー上の任意の日付または時間枠をクリック
2. その日時がプリセットされた状態でモーダルが開く
3. タイトル等を入力して「保存する」

### 3. スケジュールの編集

- **カレンダービュー**: イベントをクリック → 編集モーダルが開く
- **リストビュー**: カードの「✎」ボタンをクリック

### 4. スケジュールの移動（ドラッグ＆ドロップ）

1. カレンダービューで週表示または日表示に切り替え
2. イベントをドラッグして新しい時間帯へドロップ
3. 自動的に保存される（失敗時は元の位置に戻る）

### 5. スケジュールの削除

- **リストビュー**: カードの「✕」ボタン → 確認ダイアログ → 削除
- **編集モーダル**: 「🗑 削除」ボタン（編集時のみ表示）

### 6. プロフィールの編集

1. ヘッダーのユーザー名をクリック → プロフィール設定ページへ
2. 各セクションで変更を行い「変更を保存」をクリック

## ローカル開発環境のセットアップ

### 必要な環境

- PHP 8.2+
- Composer 2.x
- Node.js 20+
- npm 10+
- PostgreSQL 15+

### バックエンド（API）

```bash
cd api

# 依存パッケージをインストール
composer install

# 環境変数を設定
cp .env.example .env
# .env を編集（DBの接続情報を設定）

# アプリケーションキーを生成
php artisan key:generate

# DBマイグレーション
php artisan migrate

# ストレージリンク作成
php artisan storage:link

# 開発サーバー起動（ポート8000）
php artisan serve
```

### フロントエンド

```bash
cd frontend

# 依存パッケージをインストール
npm install

# 環境変数を設定
cp .env.example .env
# NUXT_PUBLIC_API_BASE=http://localhost:8000/api

# 開発サーバー起動（ポート3000）
npm run dev
```

ブラウザで `http://localhost:3000` にアクセス。

## アーキテクチャ

バックエンドはクリーンアーキテクチャに基づいて設計しています。

```
api/app/
├── Domain/                  # ドメイン層
│   ├── Entities/            # エンティティ（User, Schedule）
│   └── Repositories/        # リポジトリインターフェース
├── Application/             # アプリケーション層
│   ├── UseCases/            # ユースケース（登録・ログイン・スケジュールCRUD等）
│   └── DTOs/                # データ転送オブジェクト
├── Infrastructure/          # インフラ層
│   ├── Models/              # Eloquentモデル
│   └── Persistence/         # リポジトリ実装
└── Presentation/            # プレゼンテーション層
    └── Http/
        ├── Controllers/     # コントローラー
        ├── Requests/        # バリデーション
        └── Resources/       # APIレスポンス整形
```

### API エンドポイント一覧

| メソッド | パス                    | 説明                     | 認証 |
| -------- | ----------------------- | ------------------------ | ---- |
| POST     | `/api/auth/register`    | 新規登録                 | 不要 |
| POST     | `/api/auth/login`       | ログイン                 | 不要 |
| POST     | `/api/auth/logout`      | ログアウト               | 必要 |
| GET      | `/api/auth/me`          | ログインユーザー取得     | 必要 |
| GET      | `/api/schedules`        | スケジュール一覧         | 必要 |
| POST     | `/api/schedules`        | スケジュール作成         | 必要 |
| PUT      | `/api/schedules/{id}`   | スケジュール更新         | 必要 |
| DELETE   | `/api/schedules/{id}`   | スケジュール削除         | 必要 |
| PUT      | `/api/profile`          | プロフィール更新         | 必要 |
| POST     | `/api/profile/avatar`   | アバター画像アップロード | 必要 |
| PUT      | `/api/profile/password` | パスワード変更           | 必要 |
| DELETE   | `/api/profile`          | 退会                     | 必要 |
